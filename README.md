# 🤖 Basic Chatbot – CodeAlpha Internship Project

## 📌 Project Overview

This project is a **simple rule-based chatbot developed in Python** as part of my **CodeAlpha Internship**.

The chatbot interacts with the user through the command line and provides predefined responses to specific messages such as greetings, status questions, and exit commands.

## 🎯 Objective

The main objective of this project is to create a basic chatbot that can:

* Interact with the user through the command line.
* Recognize predefined user inputs.
* Provide appropriate responses.
* Continue the conversation until the user chooses to exit.
* Handle unknown inputs with a default response.

## ✨ Features

* 💬 Interactive command-line conversation
* 👋 Responds to greetings
* 😊 Responds to "how are you"
* 👋 Provides a goodbye message
* 🔄 Continuously accepts user input
* ❓ Handles unrecognized messages
* 🚪 Exits when the user types `bye`

## ▶️ How to Run the Project

### Step 1: Install Python

Make sure Python 3 is installed on your computer.

Check the installation using:

```bash
python --version
```

### Step 2: Clone the Repository

```bash
git clone https://github.com/your-username/basic-chatbot.git
```

### Step 3: Navigate to the Project Folder

```bash
cd basic-chatbot
```

### Step 4: Run the Program

```bash
python chatbot.py
```

No external Python libraries are required to run this project.
